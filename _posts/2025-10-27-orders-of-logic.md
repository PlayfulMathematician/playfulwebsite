Claims come in various flavors, some are as simple as, if it rains the floor becomes wet. Whilst others use more machinery. The difference in machinery is an underpinning of metamathematical thought. But first we must start with the simplest machinery.

# Propositional Logic
In this universe there only exists claims about reality, claims about reality are what the reality is made of. This of course means claims must be about eachother. Of course this makes judging claims truth to near impossible, but let us try. Before we do that we must first figure out how to relate claims. The simplest relation is negation. If X is true the negation is false and vice versa. In fact the claim $\neg A$ is the same claim as A is false. Being the same claim is another relation between two claims. The iff relation. If $A \iff B$ then what ever the truth value of A is must be the value of B. But this puts us at an interesting situation. Consider the claim $A \iff \neg A$, this claim seems hard to judge as we don't know A. But this statement is actually false, indepedent of A, if A is true then $\neg A$ must be false, so the statement would claim that a true claim is a false claim. This obviously cannot be. Now if A were false the same thing would apply. $A \iff \neg A$ is FALSE. This is a basis of our reality, nothing about any individual claim has the ability to change the truth value of $A \iff \neg A$. Now a much less restrict relation is implication, $A \implies B$ is only false if A is true and B is false. So what is $A \implies \neg A$, well here it depends on the truth value, if A is true then the above statement is false. If A is false the above statement is true. But if the above statement is true A is false. We have formed another true statement $(A \implies \neg A) \implies (\neg A)$. So suppose you pretended A was true, and then conclude that $\neg A$ was true, you just demonstrated $A$ is false. We have found a way to deduce the value of $A$, provided you know what $A$ actually means. But in this context, it is utterly meaningless. So to understand truth, pure logic is utterly useless. We cannot start with logic and then deduce truth. We must decide on truth then deduce with logic.
